# Security Policy

## Supported Versions

Drawzware receives security updates and bug fixes on the latest version of the `main` branch.

| Version | Supported |
|---------|-----------|
| `0.1.x` (`main`) | :white_check_mark: |
| `< 0.1.0` | :x: |

---

## Reporting a Vulnerability

The Drawzware team takes security issues seriously. If you discover a security vulnerability, **please do not disclose it publicly** by creating a public GitHub issue, discussion, or pull request.

Instead, please report the vulnerability privately using one of the following methods:

1. **GitHub Security Advisory (Recommended)**:
   Submit a private vulnerability report via GitHub at:
   [https://github.com/rajesh-kayal-dev/Drawzware/security/advisories/new](https://github.com/rajesh-kayal-dev/Drawzware/security/advisories/new)

2. **Private Maintainer Contact**:
   Contact the repository maintainer privately via GitHub profile message or direct inquiry:
   [https://github.com/rajesh-kayal-dev](https://github.com/rajesh-kayal-dev)

---

## What to Include in Your Report

To help us triage and resolve the issue quickly, please include:

- **Description**: A clear description of the vulnerability and its potential impact.
- **Affected Components**: The file(s), URL route, or component affected.
- **Steps to Reproduce**: A minimal, reproducible step-by-step guide.
- **Proof of Concept (PoC)**: Code snippets, payload examples, or screenshots/recordings demonstrating the vulnerability (if applicable).
- **Environment**: Operating system, browser name and version.
- **Possible Mitigations**: Any suggested fixes or workarounds, if known.

---

## Response Process & Handling

When a vulnerability report is submitted:

1. **Acknowledgment**: We will acknowledge receipt of your report within 48 to 72 hours.
2. **Assessment & Confirmation**: We will verify the issue, determine its severity, and keep you informed of our progress.
3. **Remediation**: A fix will be developed in a private branch, reviewed, and tested.
4. **Public Disclosure**: Once the fix is released, a security advisory will be published acknowledging your responsible disclosure (unless you prefer to remain anonymous).

Thank you for helping keep Drawzware and its users safe!
